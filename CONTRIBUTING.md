# Contributing

Thanks for helping Reef grow. Bug reports and small, focused pull requests are welcome.

- Start with the [build guide](docs/BUILDING.md) and [architecture](docs/ARCHITECTURE.md).
- For bugs, include macOS/chip, display sizes, theme/quality, steps and expected behavior. Remove personal desktop content before sharing a screenshot.
- For visual changes, include before/after captures of Daylight, UV Night and Planet X.
- Check fish motion, dragging, collision clearance and frame time after scene changes. Do not trade animation time for apparent performance.
- Run the relevant tests. `npm test`, `npm run test:native` and offline WebKit cover different parts of the app.
- Keep generated apps, exports, private references, credentials and downloaded source caches out of Git.
- Include original sources, licenses and modifications for every new asset. Do not copy images or models merely because they are publicly viewable.

Useful areas: distinct fish anatomy, accessibility, energy use, desktop gesture compatibility and wider hardware testing. Please discuss substantial dependency or architecture changes in an issue first.

Contributions are submitted under the project’s MIT license; third-party content must retain its own compatible notices.
